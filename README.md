# Preliminary Anti-Collision Tool — Report Prototype

This prototype includes:
- Phase 1: Offset well data and trajectory calculation
- Phase 2: New well trajectory planning
- Phase 3: Preliminary anti-collision screening
- Rate-based positional uncertainty in m / 1000 m MD
- Common-Z screening at 5 m intervals
- CtC and SF plots with global minimum labels
- Project / report identity inputs
- Formal PDF report generation using ReportLab

PDF report format:
- Cover page without header/footer
- Subsequent pages: left header `Preliminary Anti Collision Assessment`, right Rigsis logo
- Footer: report generation date on the left and `Page X of Y` on the right
- Preliminary engineering screening disclaimer included
